# CO2 Emissions Forecasting using LSTM

This project focuses on time-series forecasting of CO₂ emissions using Long Short-Term Memory (LSTM) neural networks.

Dataset source:
https://carbonmonitor.org/

## Project Overview
- Dataset: Carbon Monitor CO₂ emissions dataset
- Techniques:
  - Data preprocessing
  - Time-series analysis
  - LSTM forecasting
  - Visualization

## Technologies Used
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- TensorFlow / Keras
- Scikit-learn

## Objective
To predict future CO₂ emission trends using deep learning techniques.
